# 100Sixteen STD — временный физический донор M4

Частный некоммерческий проект. План 100Sixteen разрешён автором только для
private / non-commercial use:
https://www.kareloh.com/kite-plans/90three-family/100sixteen/

A0 выкройки:

- [100Sixteen_Blueprint_a0_v2.pdf](https://www.kareloh.com/wordpress/wp-content/uploads/2017/02/100Sixteen_Blueprint_a0_v2.pdf)
- на той же странице плана — `100Sixteen_Panels_a0`

В коде числа лежат в `HundredSixteenLayout`. Это замена обмеров рамы Fury, пока
нет рулетки по настоящему змею. Меш Fury остаётся визуальным парусом сцены.

Координаты змея: `+X` вправо по размаху, `+Y` из паруса к пилоту, `+Z` вдоль
спины к носу. Плоскость паруса на чертеже — `Y = 0`.

## Зафиксировано (публикация + владелец 2026-10-13 + обмер A0)

Габарит и масса:

- размах 2.60 м, высота паруса 1.015 м, масса 350 г, хвост 20 г;
- Nitro Strong на ULE/LLE и LS: **23 г на трубку 81 см**
  (погонная 0.0284 кг/м) — оценка масс остальных карбоновых стержней отсюда.

Рама:

- ULE/LLE 810/810 мм, upper/lower spreader 515/783 мм;
- 5pt spine 825 мм + обрезок p200; феррула **внутренняя**, трубки **встык**;
  p200 режется по парусу (владелец), собранная спина = высота **1.015 м**,
  обрезок ≈ 190 мм;
- inner/outer standoff 295/280 мм (inner «slightly bending»).

Станции от носового шва до низа коннектора (таблица плана):

| Точка | От носа |
|---|---|
| Upper APA | 336 мм |
| Yoyo stopper | 610 мм |
| **Center Cross / T-piece** | **597 мм** |
| Inner bridle (нога inhaul) | 637 мм |
| Lower APA | 997 мм |

T-piece сидит на метке **Center Cross** выкройки A0. Обмер PDF 1:1 дал 618 мм
от острия носового треугольника; 21 мм — кончик сгиба vs «от носового шва до
низа коннектора». В коде якорь T — `CrossFromNose = 0.597`. Третья нога уздечки
крепится на inner 637 мм, на 40 мм ближе к хвосту, не в центр тройника.

Уздечка STD: upper/outer/inner 640/575/725 мм. `BridleGeometry.TryTowpoint` на
верхнем APA, нижнем APA и inner сходится, towpoint перед парусом.

Camber/billow в полёте не мерили. Их можно **посчитать** из каркаса + A0 + длин
стендофов: парус пришит к тоннелям LE/спины, стендоф задаёт расстояние рама→парус.
Для шести панелей этого достаточно. Полётное растяжение Icarex и изгиб inner SO —
калибровка, не дырка в геометрии.

## Оценка, не обмер

- массы отдельных стержней, кроме 23 г Nitro Strong: считаем той же погонной,
  остаток `350 г − рама − 20 г хвоста` кладём на парус-ламину;
- глубина пуза панелей — из длин стендофов, пока нет 3D-сборки выкройки;
- inner SO чуть гнётся — в первом тензоре как жёсткий стержень 295 мм.

## Модель

Низкополигональный proxy (пока плоский) собирается так:

```
blender.exe -b -P Tools/blender/make_100sixteen.py -- --out Assets/Models/HundredSixteen_v01.fbx
```

Это геометрический стенд для инерции и панелей, не финальный вид.
