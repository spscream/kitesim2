# 100Sixteen STD — временный физический донор M4

Частный некоммерческий проект. План 100Sixteen разрешён автором только для
private / non-commercial use:
https://www.kareloh.com/kite-plans/90three-family/100sixteen/

В коде числа лежат в `HundredSixteenLayout`. Это замена обмеров рамы Fury, пока
нет рулетки по настоящему змею. Меш Fury остаётся визуальным парусом сцены.

## Что уже можно взять из публикации

- размах 2.60 м, высота 1.015 м, масса 350 г (хвост 20 г);
- ULE/LLE 810/810 мм, upper/lower spreader 515/783 мм, spine 825 мм;
- два стэндоффа: 295 и 280 мм;
- позиции от носа: upper APA 336, lower APA 997, cross 597, inner 637 мм;
- трёхточечная уздечка: 640 / 575 / 725 мм.

`BridleGeometry.TryTowpoint` на этих якорях сходится: towpoint перед парусом.

## Чего в публикации нет и что нельзя выдумать

- точная длина составного spine после надставки;
- смещение T-piece относительно отметок 597/637 мм на чертеже A0;
- camber / billow после сборки;
- массы отдельных стержней после обрезки и фитингов.

Их нужно снять с A0-чертежа или уточнить у автора, прежде чем калибровать
`RigidKiteSim`.

## Модель

Низкополигональный proxy собирается так:

```
blender.exe -b -P Tools/blender/make_100sixteen.py -- --out Assets/Models/HundredSixteen_v01.fbx
```

Это геометрический стенд для инерции и панелей, не финальный вид.
