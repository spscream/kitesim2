# M4.3: XPBD lines and PilotHands

Дата: 2026-10-14
Статус: принято владельцем (ядро только, сцена не трогается)

Предметная часть — `docs/kite-anatomy.md` §5 и дизайн
`docs/superpowers/specs/2026-08-30-kite-simulation-design.md` §5 и §8.
Здесь только объём **этого** инкремента.

## Задача

Жёсткий 100Sixteen уже висит 60 с на нерастяжимых 45 м. Теперь стропы
становятся податливыми XPBD-связями рука→towpoint, кисти задаются из осей
ввода, асимметрия даёт поворот. Ворота: знак поворота верный; `ψ̇` линейна по
разности рук в первую секунду висения; ветвь `ψ̇ ∝ v_app` снята владельцем
2026-10-14 (не крутить `PanelAero`); висение 60 с не ломается.

Продукт-тренажёр по-прежнему `WindowSim`. Сцена, ходьба пилота, взлёт и
посадка — M5.

## Принятые решения

| Решение | Выбор |
|---|---|
| Где жить | Только `Kitesim.Core` + EditMode / `.verify-core` |
| `WindowSim` | Не редактировать |
| Сцена / галка висения | Не подключать руление |
| Стропы | Один XPBD-constraint на стропу, не многозвенный трос |
| Жёсткость | `k = 750` Н/м (середина оценки 600–900), `α = 1/k` |
| Связь | Только на растяжение: `dist < L0` → λ = 0, натяжение 0 |
| Натяжение | `T = max(0, −λ / Δt²)` после итераций субшага |
| Руки | Стик = положение кисти; `+1` = тяга вниз (world −Y), ход 0.7 м |
| Оракул | Линейность `ψ̇` по `u` в окне 1 с после 2 с трима; ветвь `v_app` снята |
| Знак | Тянем правую — `HeadingRad` растёт (вправо от пилота) |
| Если знак инвертирован | Флип оси в `PilotHands`, не в `PanelAero` |
| Если линейность не сходится | Остановиться и обсудить; не крутить панели в этом инкременте |

## Компоненты

### `LineSystem`

Две односторонние дистанции. На каждом субшаге 8 итераций XPBD (Macklin):

```
ã = α / Δt²
Δλ = (−C − ã λ) / (w + ã)
C = |attach − hand| − L0,  L0 = 45 м
```

`w` — то же жёсткотельное `1/m + r×n · I⁻¹ (r×n)`, что уже в
`RigidKiteSim.ProjectOne`. При `C < 0` связь выключена, λ не копится.

Вынесен из `RigidKiteSim`, чтобы натяжение и провис тестировались без аэро.

### `PilotHands`

Чистая функция осей `[-1, 1]` → `HandLeft` / `HandRight` вокруг стойки.
Полуширина 0.12 м (как сейчас дефолт сима). Ход 0.7 м — тот же
`WindowConfiguration.HandTravel`. Не читает устройства.

### `RigidKiteSim`

`ProjectLines` заменяется вызовом `LineSystem`. `View.Tension` — среднее
двух натяжений, не заглушка 50 Н. `RestLength` остаётся 45 м для спавна.
Допуск длины стропы в тесте висения: `|dist − 45 − T/k|`, не `≈ 45`.

## Тесты (ядро)

| Тест | Проверяет |
|---|---|
| Slack | Обе руки ближе чем 45 м → T = 0, тело не тянет |
| Stretch | При ~60 Н удлинение ≈ 60/750 м |
| Sign | T никогда не отрицательно |
| Hang 60 s | 6 м/с, симметричные руки, Y > 1, нос вверх |
| Sign of turn | Правая тяга → HeadingRad растёт |
| Oracle | Удвоение u roughly doubles ψ̇ (допуск 40 %); ветвь v_app не проверяется |

Ходьба, взлёт, посадка, сцена — не этот spec.
